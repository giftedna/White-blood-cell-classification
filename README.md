# Leukocyte Four-Class Classification from Peripheral Blood Smears (Baseline vs. Proposed)

A PyTorch convolutional neural network project for four-class leukocyte classification, providing two complete training, evaluation and visualization pipelines: a baseline model (**BaselineCNN**) and the proposed method (**OptimizedCNN**), together with comparison figures on the test set.

Four classes: EOSINOPHIL, LYMPHOCYTE, MONOCYTE, NEUTROPHIL.

## 2. Environment Setup

```bash
conda activate pyenv          # activate your local environment
pip install -r requirements.txt
```

Python 3.x; GPU (CUDA) is optional. The code detects `cuda` automatically and falls back to `cpu`.

## 3. Dataset Preparation

Organize the images following the `torchvision.datasets.ImageFolder` layout; each class subfolder name is the class name:

```
images/TRAIN/EOSINOPHIL/  images/TRAIN/LYMPHOCYTE/  images/TRAIN/MONOCYTE/  images/TRAIN/NEUTROPHIL/
images/VAL/...
images/TEST/...
```

## 4. Running Order

Run every script from the **project root directory**:

```bash
# 1) Train the two models (order does not matter; they are independent)
python train_baseline.py      # produces checkpoints/baseline.pth + results/eval_baseline.json + results/baseline_history.json
python train_proposed.py      # produces checkpoints/proposed.pth + results/eval_proposed.json + results/proposed_history.json

# 2) Evaluate existing weights on the test set (no retraining required)
#    Default "all": evaluate baseline and proposed in sequence, print each classification
#    report (precision / recall / f1-score / support) and confusion matrix values to the
#    console, and write both JSON files back to results/
python evaluate.py
python evaluate.py --model all          # same as default
python evaluate.py --model baseline     # evaluate only the baseline
python evaluate.py --model proposed    # evaluate only the proposed model

# 3) Visualization and comparison figures
python visualize.py           # Chinese-labeled plots of the proposed model -> outputs/
python make_figs.py           # English comparison figures for both models  -> figs/
python print_history.py       # per-epoch comparison CSV -> results/
```

## 5. Differences Between the Two Models (Controlled Comparison)

| Module | BaselineCNN | OptimizedCNN (Proposed) |
|---|---|---|
| BatchNorm | None | BN inside convolutional blocks; BN1d in the classifier head |
| Dropout | None | Progressive Dropout2d in conv blocks (0.1/0.2/0.3/0.4), Dropout 0.5 in the classifier head |
| Data augmentation | None | Random rotation ±15°, horizontal flip, random translation ±10% |
| Pooling / head | Flatten + fully connected | Adaptive global average pooling (GAP 4×4) + regularized fully connected head |
| Weight decay | None | Adam weight_decay = 1e-4 |

All other hyperparameters (input 120×160, batch size 64, 50 epochs, Adam learning rate 1e-3, normalization mean/std = 0.5) are identical between the two models. They are defined centrally in `config.py` for easy modification and a fair comparison.

## 6. Key Hyperparameters

Defined centrally in `config.py`: input size `120×160`, `BATCH_SIZE=64`, `EPOCHS=50`, `LEARNING_RATE=1e-3`, `WEIGHT_DECAY=1e-4`, random seed `SEED=42`.
